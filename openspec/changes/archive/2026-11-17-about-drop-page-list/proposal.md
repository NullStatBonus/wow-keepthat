# Proposal

## Why

The About page repeats a one-line guide to every settings page ("Home: features. Materials: item details. ..."). The page tree on the left already names each page, so the line adds noise. The other addons' About pages go straight from the description to the commands.

## What Changes

- Remove the page-guide sentence from the About page. About shows the name, version, one-sentence description, then Commands.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. No requirement describes this sentence.

## Impact

- `KeepThat/Options/Options.lua` (About page).
